# timetable-maker
This simple application helps schools to automanate  students' and teachers' timetables at the start of the educational year. 

Each year, schools face a major challenge in allocating students to required classes, classrooms, and then assigning each class group to teachers, especially when a school institution considered to be large. 
Many schools or educational institutions still require a teacher or other member of staff to manually write a timetable, for example, using a spreadsheet or even with the use of pins and pegboards. Some schools use software tools to simplify the process; however, the timetables still need to be pre-viewed. Thus, it would be very handy to atomise this process within a reasonable time frame.

Timetable making problem proven to be a non-polynomial (NP) type problem, indicating that it cannot be fully solved in polynomial time. There is no such an algorithm that can consider all the constraints and come up with an optimal solution in a feasible time frame. However, a problem can be solved deterministically with a heuristic approach in polynomial time.
